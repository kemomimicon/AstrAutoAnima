# 可选词库导入器

安装 Python 3.10+（含 Tkinter）后，运行 `python importer.py`。无需安装第三方库，也不常驻后台。

1. 填写 Hub 地址和管理员令牌；远程连接仅允许 HTTPS，本机可用 HTTP。
2. 设置英文组 ID、中文显示名，以及是否允许在 QQ 私聊中抽取该组。
3. 选择原有来源组 B/G/D/C/R 和安全分级 N/H/S（需由管理员人工审核）。
4. 选择 UTF-8/GB18030 的 JSON、CSV、TXT，检查预览，再点击确认同步。

JSON 可为字符串列表、含 `prompts` 或 `items` 的对象；每条可为字符串或含 `prompt`/`tags`/`text` 的对象。CSV 需要 `prompt`/`tags`/`text`/`提示词` 列。TXT 每行一条。只导入提示词文本；不会导入图片、脚本或外部路径。单次上限 10000 条，分批 500 条。组可通过 `@组ID` 抽取。

令牌仅在本次进程内使用。不要把 6185（AstrBot）、8188（ComfyUI）或 8765（Studio）作为 Hub 地址；也不要把管理员令牌发送给其他用户。同步失败时可重试，Hub 会按内容、来源、安全分级和自定义组跳过重复项。用户原有词库不会被此程序清空。
