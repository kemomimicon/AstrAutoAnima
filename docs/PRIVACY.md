# 隐私与公开包边界

## 本仓库明确不包含

- Hub 管理员/用户明文令牌、令牌交付 CSV、生产 `.env`。
- QQ 号、Bot ID、NapCat 登录态、二维码、Cookie、设备数据。
- AstrBot `cmd_config.json`、数据库、管理员/白名单和 Provider 密钥。
- 作者真实提示词库、删除墓碑、角色/画风预设和 OC 固定串。
- 作者生产 Quick 工作流及私人模型/LoRA 文件名配置。
- ComfyUI 模型、LoRA、输入、输出、临时图片和元数据。
- 反推历史、任务记录、Hub 审计、日志、备份和云服务器目录快照。

公开工作流中的 `YOUR_*` 是占位符，公开提示词池 `prompts` 必须为 0 条。示例 QQ、任务 ID、
Bot ID 都是无效演示值。

## 部署者的责任

- 把私密配置放在仓库外，或至少使用 `.gitignore` 已覆盖的文件名。
- 发布 fork 前运行 `python scripts/privacy_scan.py .`，并人工检查 Git 历史。
- 不把模型/LoRA 当作本项目代码再分发；分别确认许可证。
- 提示词导入前检查版权、角色授权、个人信息和安全标签。
- 向用户说明反推图片、提示词与生成结果的保存周期和删除方式。

## 一旦误提交

仅删除最新文件不足以撤回 Git 历史。立即轮换所有凭据、停止公开服务、清理仓库历史、重新发布，
并检查 GitHub secret scanning 与访问日志。QQ 登录信息泄漏时还需在对应平台撤销会话。
