# AstrAutoAnima 0.5.3-beta.1 · build45

本次整合 Turbo、SnapRef、角色画廊、预设多人图、管理入口和收藏修复，修订标识为 `candidate.4-favorites`。

- `/aturbo`：独立 Anima Turbo 模型，默认 10 步、CFG 1。
- `/aref`：默认同时参考角色与画风；带 `画风=名称` 自动使用 char 角色参考，并加载指定画风预设。纯画风 style 模式留待后续专门方案。
- 角色画廊和多人预设：读取已有角色预设，使用独立特征档案，先预览最终提示词再生成。
- 管理端：概览恢复 NapCat 登录助手和 QQ 状态卡；实例页恢复优云账户余额查询。
- 收藏：保存当次基础场景、动作及有效补充，排除叠加预设和可识别的人物身份、外貌标签。完整实际提示词仍通过查看提示词入口读取，历史收藏保留原样。
- QQ 收藏回执：已保存后的确认消息超时不会误报为保存失败，不重复提交操作，多选收藏继续处理后续图片。

## 更新

本次收藏修复涉及 Hub 和 AstrBot 插件，请应用服务更新包并重启对应服务。已经使用管理入口修正版的 Windows / Android 客户端可以继续沿用，成品包复用同一份已验收构建。

更新器会在覆盖前备份，并提供独立回退入口。模型、词库、预设和密钥保持原样；不会批量改写已有收藏。详细步骤见 [更新与回退说明](NEXT_CANDIDATE_UPDATE.md)。

镜像母版准备见 [AutoDL build45](AUTODL_BUILD45.md)。GitHub 与镜像发布按交付清单分别记录，旧镜像继续保留。
