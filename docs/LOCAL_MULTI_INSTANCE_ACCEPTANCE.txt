AstrAutoAnima 0.5.2 本机与多实例实机验收表
状态：待执行。此表不是测试通过声明；不要求向开发者提供密码、令牌或云密钥。

准备
使用新构建的客户端和匹配 Hub，记录构建号、系统版本、GPU、ComfyUI/节点版本。
尽量用独立测试目录及少量无敏感内容的提示词。已有安装先备份配置，不备份大量图片。
不要把公开包的空词库覆盖到现有私有词库。不要用旧二进制替代本轮新客户端。

A. 首次轻量部署
[待验收] 不装 AstrBot/NapCat 也可完成安装；Hub 仅监听本机地址。
[待验收] 无 LoRA、无预设可直接生图；配置自己的 LoRA 后可用，工作流无猜测节点编号。
[待验收] 本机直接/中文/HQ 各一张；中文仅在配置独立 LLM API 后使用。
[待验收] 原任务重跑：不修改、只角色、只画风、比例、固定种子0、补充文本各一例。
[待验收] 重跑不受今天改了默认工作流/删除旧预设影响；缺少旧快照有明确说明。
[待验收] 保存与回读角色/画风/套组；重启客户端后配置仍在。

B. 完整部署与无损切换
[待验收] 第一次选择完整服务，已有 Start-Local 和 Start-Full 入口，无需重新装模型。
[待验收] 完整→正常停止 Hub→本机：不会启动第二个 Hub，不要求 QQ 在线才能本机出图。
[待验收] 本机→完整：原本机令牌、预设、历史不丢，在线配置也不被覆盖。
[待验收] 正在生图/训练时不运行部署器；入口应拒绝冲突而非杀进程。
[待验收] 没有启用 Studio 时不会下载/启动 Studio；接入已有 Studio 不降级、不重复安装。

C. 多实例与三种客户端工作模式
准备两个独立测试 Hub A/B，可以是一台电脑上的测试配置和远端测试实例。
[待验收] 保存 A/B 两个名称/地址/令牌；凭据不在普通设置、日志或导出文件中展示。
[待验收] A 提交任务后切 B：B 不显示 A 的历史、图片、预设或云实例控制目标。
[待验收] 返回 A 可查询原任务，切换不会取消服务器正在执行的任务。
[待验收] B 断线/令牌错误/模式不符：连接失败提示清楚，当前 A 不丢、不误提交到 A。
[待验收] 快速切换、打开子页面后切换、正在刷新时切换，无旧结果覆盖新页面。
[待验收] 删除连接只删本设备连接条目，不删除远端任务、图片、模型、群设置。
[待验收] 本机/在线管理/在线服务权限独立，用户令牌不能进入管理功能。

D. 内置便捷功能
[待验收] QQ 指令拼装只复制，不自动发送；关闭入口后可再打开，无需安装。
[待验收] 中文候选可填入英文 tag；无需额外 LLM，关闭不影响手动输入。
[待验收] 局域网/私有组网/受保护隧道的说明能找到；选择说明不安装软件或开端口。
[待验收] 词库导入器小量导入/预览/查重/私聊分组设置；无需持续后台同步。
