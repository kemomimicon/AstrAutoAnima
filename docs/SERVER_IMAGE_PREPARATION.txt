AAA 0.5.2-beta.1 +40｜服务器装机与镜像准备
2026-10-20｜公开装机候选，不是已经验收的社区镜像

0. 范围和费用
本包只准备代码、模板、检查工具和说明，不创建/开机/续费/关机/发布云资源。
从新建的干净测试实例开始，不在现有业务服务器覆盖重装，不把业务盘制成公开镜像。
开卡前记录实例 ID、区域、预估时长和关机方式；完成测试及时关机。
制作镜像时平台要求实例保持开机；镜像任务完成后再次确认实例状态。
不要仅停止 Hub 就当作云实例已停止。磁盘等费用与计算实例状态分别核实。

1. 先选对母版
优云官方说明：使用平台基础镜像（容器类型）制作可发布的自制镜像。
虚机系统镜像不能发布社区；从他人社区镜像派生不能据此重新公开。
在控制台确认来源和类型，不因为旧机“已经装好了”就沿用。
官方：https://www.compshare.cn/docs/operation/image/imagecommunity
补充：https://www.compshare.cn/docs/operation/gpufaq
镜像制作、克隆验证、提交审核分别是不同阶段。审核时间以平台为准。

2. 装机候选的使用
完整解压 Linux 懒人包。使用包内 tools/deploy_project.py，不用作者私有更新脚本。
复制 examples/deployment-plan.linux.json 到包外，填写新实例实际路径和部署档位。
先执行：sh Deploy-Linux.sh --plan /absolute/path/my-plan.json
确认目标为独立目录、模型选择和网络选项，再追加 --apply。
本机路线 local 不需要 AstrBot/NapCat；服务器模式 full 使用已有适配器。
建议首先 local 做最小生图，之后在同目录补齐 full，正常停止旧 Hub 再切换档位。
两个档位共用代码和模型，但配置/令牌/任务数据隔离；单个 Hub 不同时接两条执行路线。
头部所有步骤必须由使用者填实际路径，不复制作者 /workspace 部署路径。
用源码包需自行构建客户端；懒人包是否带 Web 以该包的构建说明为准。

3. 最小依赖优先
先安装 Python、ComfyUI、Anima 基础模型和 Hub；先让无 LoRA 的 Quick 跑通。
中文转换另外配置自己的 LLM；反推、SeedVR2、局部修复、Studio 分别按需安装。
已有训练环境不要被安装器覆盖。未选择功能不应启动额外服务或下载模型。
外部 Python 依赖和部分节点未完整锁版，首次干净装机后必须记录实际 pip/Git 版本，
通过验收的组合再冻结为镜像基线。不要声称包内已包含一套实测 GPU 环境。
public comfyui/dependency_manifest.json 声明节点接口，不等于二进制运行环境锁文件。

4. 推荐母版与演示分离
母版：安装依赖和公开包，保持未登录、未绑定个人凭据、未产生私人数据的状态。
演示/验收实例：使用临时个人令牌、测试 QQ、少量自编提示词进行测试和录屏。
完成一次私有镜像后，必须从它创建一台新实例复测；不能只测原机器。
若在同一实例录制后制镜像，所有测试账号、缓存、数据、凭据和历史都必须明确清点。
本次没有提供自动删除脚本：确认目标和保留范围前，不运行全盘清理、rm -rf 或强制清库。

5. 不允许随公开镜像保留
Hub 管理/用户令牌、runtime-env*.json 的真实值、部署计划的凭据、非空用户注册表；
AstrBot API/Provider 密钥、群/用户绑定和会话数据库；
NapCat/QQ 登录资料、扫码登录缓存、平台 Bot Token、Studio 会话；
LLM/Civitai/Hugging Face/Git/云 API 凭据、SSH 私钥和作者 authorized_keys；
浏览器/Jupyter 登录资料、shell 历史、命令日志、崩溃转储、备份、下载目录及临时文件；
生成图、输入图、私人任务/反推/收藏/预设、训练数据及未获公开许可的权重和词库。
不能只检查 /workspace；平台镜像还可能包含 /root、/home、/tmp、/start.d 等状态。
这些是检查范围，不是自动删除授权；平台的必要启动组件不要盲删。

6. 克隆首次启动（发布阻断项）
每台克隆独立生成新 Hub 管理令牌/普通用户凭据；不能把母版随机一次的令牌复制给所有人。
用户重新配置自己的 API/机器人/投递目标，首次启动不自动发送平台消息、不跑 GPU 任务。
QQ/NapCat 未登录；自动云关机私有实现不在公开候选中；群等级默认关闭。
Hub/ComfyUI 默认仅回环监听。手机访问需由部署者明确配置受保护访问方式。
确认克隆没有作者 SSH 公钥、默认万能密码、预置个人云实例控制目标。
本候选还没有自动“整机脱敏 + 首启凭据再生”的镜像封装器，不能按已具备该能力宣传。
可先发布安装包/教程；镜像必须等这些项实测通过后再公开。

7. 只读检查工具
python tools/image_release_audit.py --root /path/to/managed-install --root /root --root /home --root /tmp
可增加已确认属于镜像的额外目录。工具不联网、不停止服务、不删除文件，不输出文件内容。
只给风险清单；未指定目录、压缩包内部、系统账号/平台状态仍需人工检查。
有风险或扫描不完整时返回非零。零退出也只代表所选范围未发现规则命中，不是发布许可。
最后在控制台制作私有镜像，克隆复测 SERVER_ACCEPTANCE.txt 后，再提交社区审核。
