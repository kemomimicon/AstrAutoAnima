# 项目美术与开屏

项目维护者于 2026-09-23 明确授权将现有主题图标、欢迎插画和 OC 开屏作为项目公开资源随包提供。它们不再按私人客户端素材排除；这不代表其他私人图片、角色词库或服务器数据也被授权公开。

资源在 `clients/flutter/assets`，精确路径与 SHA256 在根目录 `artwork-manifest.json`。仅复制已授权成品，不包含工作区草稿、私人生成记录或训练数据。

复用现有 Flutter 动画：约 2.6 秒的一次性角色动作、图片加载失败回退、1.5 秒加载等待上限、系统减弱动画时跳过、退出时取消定时器和释放图像。主题图标加载失败回退到原生图标。

本次按 oc-splash-animation 工作指南检查并恢复现有资源及生命周期，没有重新生成图片、没有接入收费图片 API。静态资源已经人工查看；客户端自动化测试覆盖启动退出。未完成所有机型的真实帧率测试，不宣称所有设备稳定 60 fps。

不要只把图片复制到旧 APK 旁：开屏和主题需使用包含这些资源的新客户端构建。源码包和美术资源包可用于自行构建；Web 懒人包包含对应 Web 构建。
