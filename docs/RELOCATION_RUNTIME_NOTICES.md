# 搬家工具运行时说明

Windows 工具使用 Python 3.12.14、Tkinter/Tcl/Tk 和 PyInstaller 6.22.2 构建。
分发包附 Python 许可证；Tcl/Tk 运行时资源由打包器随 EXE 收集。
AAA 源码适用项目 LICENSE。PyInstaller bootloader 的分发例外允许打包应用按自身许可证分发。

这是本地未签名的候选构建，不是微软签名或商店认证软件。
工具不调用网络接口，不包含用户配置、模型、词库、令牌或实际服务器地址。
默认示例目录 D:\QQ-comfyui 来自本次恢复目标，可以在界面另选。

运行时会在系统临时目录解包自身运行环境，这是 EXE 的正常启动过程；
它与用户的服务安装目录不同，不会将 Hub 部署到该临时目录。
修复与复制均需在界面明确确认。不会自动启动目标服务或删除源目录。
