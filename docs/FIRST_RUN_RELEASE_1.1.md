# 首张图启动向导 1.1

这是 AstrAutoAnima 0.5.0-beta.2 的独立安装后辅助工具，不是重装包。原完整发行版、服务器、插件和客户端无需因本工具强制升级。

## 下载哪个

- **Windows.zip**：推荐新手。完整解压，双击 `AstrAutoAnima-FirstRun-Wizard.exe`，不需要 Python。不要只复制 EXE，保留 `docs`。
- **Source.zip**：Python 3.10+ / Tkinter 源码版；Windows 和有桌面的 Linux 可用。无桌面服务器仍使用原 Admin 和服务管理方式。
- **SHA256SUMS.txt**：下载校验。本包无商业代码签名，不要关闭系统安全软件。

## 本次新增

九步中文界面：安装识别、授权、投递、用户、随机词库、角色词典、备份保存、首张图和工具帮助。

- 拦截误填的 12 位 AstrBot Key 前缀，区分 API Key 与 Hub 管理员 / 普通用户令牌。
- 用户确认后执行只读鉴权、实际 API 工作流的节点与枚举模型检查。
- 通过既有 Hub 提交一次普通英文生图，默认不投递 QQ；查询任务，下载并校验图片大小与 SHA256，可预览 PNG / 另存图片。
- 防重复提交；超时不自动重试，任务 ID 可恢复查询；不把排队或无图片成功状态当作验收完成。
- 本地词典 JSON 导入或明确许可确认后的公开源在线装配；保存前暂存、原文件备份，不覆盖收藏和 edits。
- 内置词库编辑器、用户令牌管理器和离线中文操作指南，包含模型、AM 0.7.1、首次图片和常见错误。

## 安全与验证范围

不包含真实密钥、账号配置、私人词库、第三方角色数据、模型权重或训练服务接口。加载和切页不写运行文件，下载 / 鉴权 / 生图分别确认，不自动重启服务或改防火墙。

已覆盖工具单元测试、模拟 HTTP 鉴权到返回图片链路、Windows 可执行文件隔离临时安装流程、公开源码和 ZIP 隐私扫描。完整回归结果见对应提交的 GitHub Actions。
**模拟首图不是实际 GPU / QQ 实机联调**；请按向导在自己的设备确认实际图片、Service 用户权限和 QQ 收件。普通生图无需随机库或 LLM；高级模型、角色 LoRA 和 QQ 登录仍由用户配置。
