# Windows 搬家与路径修复工具

版本：1.0-candidate.3，2026-10-22。本地修复候选，未上传 GitHub。替代 candidate.2；请关闭旧工具后使用新版 EXE。

本版修复“浏览中新建空目录后仍被拒绝”和旧环境索引触发 `UnicodeDecodeError` 两个问题。支持未创建的目标或已存在的空目录；支持 UTF-8（含 BOM）、本机 ANSI 编码（中文 Windows 通常为 GBK/CP936），并尊重 Python 索引源码声明的编码。修改时保留原编码、BOM 和换行；未知或无法无损写回的编码会明确提示具体文件，不丢弃字符、不强行覆盖。

独立 EXE 检查用户 Python 时继续隔离自身 DLL 搜索路径，避免串用运行环境。

适用于同一台 Windows 电脑上，由 AAA 懒人包创建、含 `.aaa-managed-install`、`Start.cmd`、`services.json`、`runtime-env.json` 和 `hub` 的完整安装目录。不是 ZIP 解压目录，不支持跨电脑或跨系统迁移。

## 本次用户：保留 D:\QQ-comfyui

1. 完整解压工具 ZIP，双击 `AAA-Move-And-Repair.exe`。不需要另装 Python，不需要管理员权限，不要在压缩软件中运行。
2. 选择默认的 **就地修复（已经改名/复制）**，当前安装目录保留 `D:\QQ-comfyui`。
3. 先正常停止 Hub、AstrBot，以及安装目录内的 ComfyUI。关闭客户端不代表后台服务停止；控制台启动通常用 Ctrl+C 正常退出，桌面版需退出后台服务。不能确定时不要结束所有 python.exe。
4. 点“检查并执行（自动备份）”并确认。端口仍占用时工具停止并提示服务名、端口，不强杀。
5. 等到“路径修复与 Python 定位检查通过”，再从 `D:\QQ-comfyui` 运行原 `Start.cmd`，确认 Hub 在线、客户端授权、普通单图与返图。

不要重装、覆盖词库或生成新令牌。窗口会显示备份目录 `path-backup_日期时间_随机后缀`；备份可能含密钥，请私密保管，不要发群。

## 从下载/临时目录搬到固定位置

1. 正常停止相关服务、部署器、编辑器及其他会写入安装目录的程序。
2. 选择 **搬家（完整复制，保留原目录）**。
3. 当前目录选旧 `Start.cmd` 所在目录；目标选长期保留的位置，例如 `D:\qq-comfyui-robot`。可以在“浏览”中新建并选择空文件夹，也可以直接填写尚未创建的路径。需要完整副本及余量空间。
4. 确认后先盘点、检查冲突和链接，再完整复制并逐文件回读 SHA256，然后备份并修复新目录路径。
5. 从新目录的 `Start.cmd` 启动，验收 Hub、授权、词库数量、预设、普通单图和返图。不要两套同时运行。
6. 原目录不会删除。验收前不要清理原目录；清理不属于本工具功能。

目标为空才可使用（隐藏文件也算内容）。非空目录、目录联接/符号链接仍拒绝，不合并、不覆盖。若目标已有旧版失败留下的文件，不要为重试而直接删除；保留现场，另选空目录。已经手动完整复制好时请选择“就地修复”。外部 ComfyUI、AstrBot Desktop 数据、外部模型库不随此操作搬迁，仍按原位置引用。

## 修改范围与保护边界

- 只更新服务工作目录/可执行程序路径，环境、上次计划和安装内 AAA/AM 配置的白名单路径字段。密钥、URL、端口、提示词、模型名和参数值保持不变。
- 模型/词库的路径引用可以随根目录改变，但不编辑其内容。搬家模式原样复制目录内模型、词库与密钥配置并校验，不删除或修改源文件。
- 相关虚拟环境仅修复 `.pth`、`.egg-link`、editable finder 中的旧根目录和必要的 `pyvenv.cfg` 路径。不运行 pip，不联网，不升级或重建环境。
- AstrBot 的 Windows CLI 启动器可能嵌入旧 Python 路径。工具改为通过对应 Python 调用已安装的 console entry point，不改 EXE 二进制。
- 不全盘替换，不改工作流内部自定义路径、任意第三方脚本或历史任务记录。外部插件配置、特殊节点、手写脚本的绝对路径仍可能需要人工核对。

## 备份、失败与恢复

所有待改文件先备份并回读，再逐项原子写入。报告只列路径和哈希，不打印密钥值。没有需要修改的项目时只检查，不创建无意义备份。

修复或 Python 定位检查失败时，尝试恢复本轮已修改内容；若并发修改、文件占用或回滚失败，停止并明确提示，不强制覆盖。断电/强行结束程序不保证自动回滚，请保留目录和备份联系维护者。

搬家中断后原目录保留，新目录带 `.aaa-migration-incomplete`，**不能启动这个半成品**。本版不自动续传或清理；修正原因后选另一个空目录或不存在的目标重试。新版懒人包启动器会阻止启动未完成副本，旧安装的 Start.cmd 不具备此检查，更需遵守提醒。

备份 `manifest.json` 记录相对路径与前后哈希，`originals/` 存原内容。人工恢复时先停服务，按同一相对路径逐项恢复；不要用旧备份覆盖后来新增的配置。含密钥的备份和完整 runtime-env.json 不要公开。

## 常见问题

- **端口占用**：后台未退出或其他实例占用；不自动杀进程，不绕过检查。
- **选新目录仍提示非空**：检查是否存在隐藏文件或上次复制残留；不要删除不明文件，改选真正的空目录。文件夹名字是新的不代表里面为空。
- **旧版 UnicodeDecodeError**：先确认标题为 `1.0-candidate.3`。新版兼容本机 ANSI 索引，不需要手动把所有文件转成 UTF-8。
- **新版提示无法识别编码/新路径无法用原编码保存**：保留原文件，截取工具显示的文件路径和错误类型给维护者，不发送文件内容或完整配置。原编码不能表示新目录名时，改用普通中文或英文字母目标名；工具不会用问号替换字符。
- **缺安装标记/配置/Hub**：不是完整安装根目录，不要新建空标记或空 JSON 冒充。
- **Python/包定位失败**：基础 Python 可能也被删/移，或者原环境就不完整。修复会回滚，不下载重装来掩盖问题。
- **目录联接/符号链接**：拒绝跨入真实模型库或其他目录，不要删除链接目标；需人工规划。
- **空间不足**：复制需要第二份空间，不以删除源文件换空间。
- **修复锁存在**：确认其他修复进程已经退出后再处理残留锁，不能多开。
- **密钥要不要重填**：不需要，原值保留；改名不意味着要新建 API Key 或 Hub 令牌。

## 新懒人包预防措施

独立安装目录默认改为用户目录下 `AstrAutoAnima-install`，不再跟随下载包/临时解压位置。首次页面、确认弹窗与部署后说明都提醒长期保留目录、不能直接改名。

Windows 安装中心新增“⑥ 搬家 / 改名后路径修复”。新版启动入口发现 Hub 工作目录不匹配时在启动任何服务前停止，避免误用旧实例。下载新 ZIP 不会自动更新已有安装；独立工具不覆盖部署器代码。
