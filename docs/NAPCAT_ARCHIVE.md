## 使用方式

- **已经安装 NapCat**：继续使用现有安装，QQ 登录和 AstrBot OneBot 对接见 [NapCat 设置说明](NAPCAT_SETUP.md)。
- **首次安装**：进入 Releases，按操作系统与部署方式选择附件，按该版本发布页完成安装。Code → Download ZIP 仅用于取得源码。
- **旧 AAA 向导**：其 Windows 入口固定为 v4.18.38，并校验大小与 SHA256。v4.18.42 等其他版本按留档发布页安装，完成后回到 AAA 的 QQ / OneBot 对接步骤。已有同版本入口文件可选择向导的“本地文件”。
- **查阅源码**：使用上述社区留档仓库。旧安装脚本中的版本、附件名和校验值需要配套，不能只替换仓库名。
