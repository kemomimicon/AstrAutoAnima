# 重跑热修复：0.5.0-beta.2-remake.1

适用 Windows 和 Linux。修复的是任务恢复逻辑，不是 Windows 专属问题。
本版包含 windows.2 的插件修复；不包含个人词库、令牌、工作流配置或训练组件。

## 已安装用户

1. 等待当前任务完成，正常停止 AstrBot，备份实际运行的插件代码目录。
2. 下载 AAA_Remake_Hotfix_0.5.0-beta.2-remake.1.zip。
3. 将 plugin_files 内的文件按原目录结构复制到实际 astrbot_plugin_comfy_bridge 插件目录。
   Windows AstrBot Desktop 常见位置为 %USERPROFILE%\.astrbot\data\plugins\astrbot_plugin_comfy_bridge；
   自定义部署以实际运行实例为准，不是 AstrBot EXE 安装目录。
4. 不删除原文件夹，不覆盖 plugin_data、data、词库、预设和配置。本补丁不附带这些数据。
5. 启动 AstrBot，确认插件版本为 0.5.0-beta.2-remake.1，再进行一次测试。

已经使用 windows.2 的用户只需更新插件；Hub、客户端、模型和 ComfyUI 无需重新安装。
早于 windows.1 的部署还需按 WINDOWS_COMPAT_HOTFIX.md 完成平台兼容组件更新。
完整 Windows/Linux 懒人包及完整插件包也已包含本次修复。
完整插件包含公开空库示例，已有用户优先使用上面的代码补丁，避免覆盖自己放在插件 data 中的词库。

回滚：停止 AstrBot，将本次覆盖的代码文件从备份还原，然后重启。不要还原或删除生图期间新增的个人数据。
不要将此公开版补丁覆盖到 0.5.1/0.5.2 或自行修改过的源码；本地开发版有独立补丁。

## 重跑的三种含义

- 不填补充内容、不勾固定种子：复用原任务工作流快照，换种子再抽一张。
- 不填补充内容、勾固定种子：保留原快照和种子，正常情况下应得到相同或非常接近的图。
- 填普通补充内容：默认按文字直接追加，不调用文本模型、不删除原提示词。
  只改文字时直接修改原快照的正向编码节点，保留模型/LoRA、负面、画布和采样设置。

示例（回复已有生成图）：

```text
/aremake
/aremake 固定种子
/aremake 固定种子 sunset, rainy street
/aremake 步数=35 CFG=7 sunset
/aremake AI改写：将自行车颜色改成蓝色，保留石墙和雨天街道
```

最后一种需要服务端文本模型。只有明确以 AI改写：或 AI改写: 开头才会重写整段；
模型仍可能遗漏细节，不承诺精准保留。空的 AI 改写请求会报错。
默认追加不会自动翻译中文，也不会理解“去掉红色”来删除原词；推荐输入英文标签。
追加冲突标签会同时保留新旧标签，如需移除旧描述请明确使用 AI 改写或编辑原提示词重新发起任务。

角色、画风、比例等结构调整，或 AI 改写，会使用当前模板重建任务。
这条路径已修复 steps/CFG/sampler 字段错配，恢复实际记录的采样器、步数、CFG、调度器和 denoise，
而不是悄悄使用 30 步/CFG 5。用户本次明确指定的参数优先。
该路径不是逐节点复现，不承诺当前模板、模型文件或全局配置改变后仍生成原图。

客户端的现有补充文本框与引用令牌协议继续可用，不需要换 APK/EXE 才能生效。
旧客户端可能仍显示“文字修改需文本模型”的旧提示；以本版服务端规则为准。
客户端源码的提示文字已同步更新，现有预编译客户端不在本次重新构建范围。

## 支持边界与验收

- 快照追加支持沿正向 conditioning 连接找到的 CLIPTextEncode / AnimaPromptBatchEncode。
  未支持的文本节点、动态文本输入、正负共享文本节点会报错，不退回默认工作流。
- 合批任务抽出一张不能保证原始噪声完全一致，仍拒绝合批固定种子；可不固定种子。
- 原任务缺少快照时仍报错；不猜测旧图参数。
- 固定种子不是局部重绘。改提示词后即使参数一致，构图仍可能变化。
- 相同种子跨模型文件版本、节点实现、GPU/依赖版本，也不保证逐像素相同。

建议用“bicycle, stone wall, rainy street”一类中性场景验收：
原图设 40 步、CFG 9，固定种子重跑，再追加 sunset；
核对 PNG 元数据中 seed、steps、cfg 和原提示词均被保留。
自动测试检查实际提交图及记录；本机未连接真实 GPU 服务做视觉验收。
