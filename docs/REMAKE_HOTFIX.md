# 重跑修正补丁：0.5.0-beta.2-remake.2

取代 remake.1，仅修 bug，Windows/Linux 通用。
不增加指令前缀、按钮、模式、设置或模型检测页面；保持原有客户端和 QQ 操作方式。

## 本次修复

- 正确继承原任务实际 steps、CFG、sampler、scheduler、denoise，用户明确指定的值优先。
- 文字调整仍使用原有 AstrBot 文本 Provider，不需要新 API，也不用加任何前缀。
- 内部不再用模型生成的整段文字直接覆盖原提示词。
  模型只返回局部修改位置和新增词，程序保留其余原词。
  格式错误、越界或试图删除半数及以上原词时停止任务，不悄悄生成丢失场景的图片。
- 未配置文本 Provider 时仍按原逻辑明确报错；角色、画风、比例等参数调整无需 LLM。
- 不修改文字时仍走原任务快照重跑：固定种子沿用原种子，否则换种子。
- 撤回 remake.1 的默认追加逻辑、AI改写前缀和客户端文案变更。

## 已安装用户更新

1. 等待任务完成，停止 AstrBot，备份实际插件代码目录。
2. 下载 AAA_Remake_Hotfix_0.5.0-beta.2-remake.2.zip。
3. 将 plugin_files 中的文件按原相对位置覆盖到实际 astrbot_plugin_comfy_bridge 目录。
4. 不删除原目录，不覆盖 data、plugin_data、词库、预设或配置。本补丁不含这些数据。
5. 启动 AstrBot，确认版本为 0.5.0-beta.2-remake.2。
6. 如需回滚，停止 AstrBot 并还原代码备份，不动个人数据。

已经装过 windows.2 或 remake.1 的用户只更新插件；Hub、客户端、模型和 ComfyUI 不用重装。
早于 windows.1 的部署还需参考 WINDOWS_COMPAT_HOTFIX.md 完成平台兼容更新。
Windows/Linux 懒人包和完整插件包同步包含本修复。
完整插件包有公开空库示例，已有用户优先用代码补丁，避免覆盖自行放入 data 的词库。
0.5.1/0.5.2 开发版不要使用本公开补丁，使用对应本地开发版补丁。

## 使用及验证边界

继续在原“重跑一张”的补充框填写调整，例如“把自行车改为蓝色”或 blue bicycle。
不新增任何前缀或选项。固定种子且不改文字/参数时，相同图是预期行为。
文字或结构调整仍按原逻辑重建任务，不承诺不同模板/模型文件/依赖下逐像素复现。
改提示词不是局部重绘，即使固定种子构图也可能变化。
内部保护防止整段覆盖，但不能保证模型对所有自然语言要求都理解正确。
较大范围文本修改会因保护而报错，可缩小调整范围；不会偷偷退回旧的整段覆盖。
合批固定种子、权限与安全检查保持不变。无真实 GPU 生图或真实文本模型视觉验收；
回归测试覆盖实际方法、采样参数和模拟模型返回值。
