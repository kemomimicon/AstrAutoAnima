AAA 搬家与路径修复 1.0-candidate.3
2026-10-22 空目录与文件编码修复版

先关闭旧版工具，完整解压本包，再双击 AAA-Move-And-Repair.exe。
确认窗口标题为 1.0-candidate.3。不需要重新安装 Python。
不需要新建令牌，也不要删除模型或词库。

一、从下载/临时目录搬到长期使用的目录
1. 正常停止 Hub、AstrBot，以及原安装目录内的 ComfyUI。
   不确定哪些进程属于它们时，不要直接结束所有 python.exe。
2. 选择“搬家（完整复制，保留原目录）”。
3. 当前安装目录：选择包含原 Start.cmd、services.json、runtime-env.json 和 hub 的目录。
4. 搬家目标：例如 D:\qq-comfyui-robot。
   可以通过“浏览”新建并选择空文件夹，也可以输入尚未创建的目录。
   文件夹必须为空，隐藏文件也算内容。不要选原目录的子目录。
5. 点“检查并执行（自动备份）”，阅读确认信息后继续。
6. 等工具明确提示复制、路径修复和 Python 定位检查完成。
7. 到新目录双击原 Start.cmd，验收 Hub 在线、客户端授权、词库数量、普通单图及返图。
   不要同时启动两套；验收前保留原目录。工具不会替你删除它。

二、已经改名或完整复制到 D:\QQ-comfyui，只想保留当前位置
选择“就地修复（已经改名/复制）”，当前安装目录选 D:\QQ-comfyui。
这种情况不用再搬一次，也不用填写搬家目标。停服务后执行并验收即可。

三、保护范围
修复前自动备份所有待修改的小型配置与环境索引，并回读检查备份。
只调整限定的路径引用；不编辑模型文件、词库内容或密钥值。
搬家模式会原样复制安装目录内的数据，不改源文件；外部模型库不搬迁。
不联网、不重装环境、不下载模型、不强杀进程，也不自动启动服务。
备份目录名为 path-backup_日期时间_随机后缀，里面可能含密钥，请私密保管，不要发群。

四、如果仍然报错
目标非空：不合并、不覆盖；保留里面的文件，另选一个真正的空目录。
如果上次搬家中断，且目标有 .aaa-migration-incomplete，不要启动这个半成品。
编码问题：新版支持 UTF-8、UTF-8 BOM 和本机 ANSI（中文 Windows 通常为 GBK/CP936）。
无法安全识别或无损写回时会指出具体文件。保留原文件，把错误提示截图发给维护者。
不要自行批量转码，也不要发送 runtime-env.json、备份或其他含密钥的完整文件。

本版经过本地自动化和真实 Windows 虚拟环境检查，未在你的电脑运行或验证 GPU 生图。
EXE 为未签名本地构建；请从维护者获取并核对 SHA256，不要关闭安全软件。
更详细的保护、回滚和限制见 README_使用说明.md。
