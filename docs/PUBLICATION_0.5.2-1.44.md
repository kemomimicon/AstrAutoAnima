# 0.5.2-1.44 联合发布准备

本轮目标是把新版本、完整部署视频和 AutoDL 公开镜像一起发布，不是继续发布旧的 0.5.0-beta.2。
目前只完成本地仓库候选与材料准备；原实例和已保存镜像保持原样，未推送或公开发布。

## 版本标识

| 用途 | 标识 |
| --- | --- |
| 对外名称 | `0.5.2-1.44` |
| 插件、仓库内部发行版本 | `0.5.2-beta.1` |
| Hub Python 包版本 | `0.5.2b1` |
| Flutter 源码与既有客户端构建 | `0.5.2-beta.1+44` |
| 部署入口修订 | `entryfix.1` |

对外名字不用于强改 Python/Flutter 包管理器版本，避免破坏现有版本校验。新旧包以清单和 SHA256
区分，不覆盖以前发布附件，也不把源码候选伪装成已重编译的 Windows/Android 二进制。

## 本地源码整合

从已有、逐文件校验通过的 build44 公开源码候选整合插件、Hub、Flutter 源码、工作流、自定义节点、
部署和管理工具、AM 指引、Studio 可选接入及其许可说明。源码库保持空词库，不加入镜像里的 G/V 资源、
角色词典内容、模型、个人账号配置或 SSH 资料。

同时保留远端旧版已经公开的兼容补丁与回归测试，不因更新基线而丢弃：

- 提交前按目标 ComfyUI 枚举匹配 LoRA 名称，保留正确分隔符，不按文件名猜选。
- 无槽位动态画风检查已有 LoRA、连线索引及正负 CLIP 一致性。
- Windows 不读取 Linux 休眠锁状态，Linux 的 opt-in 锁和 fail-closed 行为保留。
- 反推记录使用实际本地目录，拒绝宽泛根目录、链接和 Windows reparse 路径。
- 角色词典编辑文件跟随真实词典目录，不固定到作者路径。
- 输出目录创建前做路径检查；同时保留 build44 的空闲任务检查、48小时下限和文件变化检测。
- 一处读取中文工作流的测试显式指定 UTF-8，避免 Windows GBK 默认编码导致误报。

build44 的预设并发保存、重连、QQ 官方消息关联、词库/造型等新内容保留；未引入新的 LLM 改写流程。
兼容合并只发生在本地候选，昨天保存的镜像仍是原字节内容，不能宣称已经被本次修正。

## 本地验收边界

当前 Python 3.12 本地工具、插件、Hub 测试通过；结构和仓库隐私检查通过。
Linux 专用测试、私人数据相关测试等跳过项不能当作通过。弃用警告保留，未以升级整个环境掩盖警告。
独立 CI 配置覆盖 Python 3.11/3.12，但本轮没有推送，不能声称远端 Actions 已执行成功。

完整源码归档不等于编译客户端、安装懒人包或云镜像：后续联合发行还要对最终各端二进制、
嵌入 Web、版本清单和压缩包再次核对，不能用旧二进制冒充重新构建。

## 抢到卡之后

按 [发布检查表](AUTODL_IMAGE_PUBLISH.md) 在独立新实例验收恢复、凭据、首图、QQ、客户端与扩展，

重新保存和恢复验证；已登录个人账号的验收实例不能直接公开。
